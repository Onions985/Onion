洋葱小站就是你现在看到的这个网站。它是我自己设计、开发并持续维护的个人空间，用来写技术博客、展示独立项目，也记录工作之外的日常。

## 为什么做这个小站

做产品时会积累很多零散的东西：一次排查问题的过程、一个功能的设计取舍、刚完成的作品，或者值得留下的一张照片。我希望有一个地方把它们慢慢整理起来，也让第一次来的人能够认识我、了解我在做什么。

因此，小站围绕博客、项目、手记和关于四个部分展开。首页提供精选内容和最近的记录，近况收在右下角的小入口里，需要时再展开。

## 阅读与交流

博客可以按标签浏览，也可以直接搜索。长文章提供目录和代码复制，同一系列的文章可以顺着读下去。项目页展示功能模块、截图与开发过程中的取舍；手记则保留更轻松的文字和照片。

读者可以直接留下昵称和评论，由我审核后公开展示。想持续关注新文章，也可以使用 RSS 订阅。

## 给自己做一套顺手的创作工具

内容不只停留在展示页面。管理后台支持 Markdown 编辑与预览、图片上传、内容搜索、分页、置顶和评论审核。文章、项目与手记都可以先保存草稿，准备好后再发布。

草稿和公开版本分开保存，这样我可以继续修改一篇文章，而读者仍然看到上一次确认发布的内容。博客的中英文版本也可以分别维护，缺少英文版本时会保留中文原文。

## 技术实现

小站使用 **Nuxt 4、Vue 3、TypeScript、Nitro 和 MySQL 8**。页面、管理后台和 API 放在同一个应用里，内容与发布状态保存在数据库中，图片通过统一的媒体管理流程上传和引用。

对一个由个人维护的网站来说，功能完整之外，我也希望它容易部署、容易修改，并且能随着自己的使用习惯慢慢调整。
