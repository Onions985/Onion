AI DevOps 是面向个人开发者和一人公司的研发工作台。一个产品中的 Android、服务端与 Web 工程可以集中管理，开发环境、构建任务和交付记录也能在同一个工作区里查看。

## 把分散的研发流程组织起来

- **多项目工作区**：按主项目组织不同技术栈的子项目，保留各自的工作台和操作状态。
- **开发环境管理**：管理本机工具链、Docker 环境和项目环境配置，让项目使用的工具与连接更容易确认。
- **构建与交付**：提供 Android 打包与设备安装，以及 Java、Go、Web 的相应构建、运行和发布流程，展示真实日志与执行结果。
- **日常开发工具**：把 Git 管理、数据库工作台、Redis 和项目 Skills 接入统一入口。
- **AI 辅助**：连接不同模型服务，用于受控的项目分析、SQL 查询辅助与失败诊断。

## 本地优先，保留工具链的边界

桌面客户端使用 Go、Wails、React 和 TypeScript，本机数据保存在 SQLite；远程服务使用 Kotlin 与 Spring Boot。平台在现有构建工具之上组织工作，不要求把所有项目改造成同一种工程结构。

构建、上传和部署分别记录执行结果，方便定位失败环节、追溯项目环境。AI 可以辅助分析和诊断，执行过程保留明确的参数与操作记录。
