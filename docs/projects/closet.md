Closet 是一个围绕女性日常衣物管理展开的个人项目。它想解决的事情很具体：衣橱里有什么、放在哪里、哪些还能穿，以及已经买下的衣服怎样被更好地使用。

## 先从记录与查找开始

不必一次填完所有信息。添加单品时，先用主图、名称和分类完成记录，再按需要补充品牌、尺码、颜色、材质、季节、购买信息和备注。

衣物多起来之后，可以通过名称、品牌、收纳位置和备注搜索，结合分类、筛选和排序找到目标。衣柜、抽屉、收纳箱与待洗、送洗、修补等状态，也都成为记录的一部分。

## 从物品列表走到衣橱全貌

品类、品牌、购买平台、价格和购买月份各自提供一个观察衣橱的角度。图表可以回到对应物品列表，帮助用户看到数字背后的具体衣服。未填写的信息保留为空，避免把缺失记录当成真实结论。

私密尺码档案用于记住身体尺寸以及不同地区、品牌的常穿标码；衣橱指南则提供穿搭、护理、收纳和换季知识，让整理衣物成为能够长期坚持的日常习惯。

## 私人记录与主动分享

衣橱里的照片、收纳位置、购买信息和尺码属于个人资料。圈子里的内容来自用户主动发布，私人记录不会自动变成公开动态。圈子支持图片分享、点赞和评论，目前继续通过内测完善交流体验和管理流程。

## 多端实现与持续迭代

项目包含 Android、iOS、服务端、公共产品文档与独立介绍官网。Android 使用 Kotlin、Jetpack Compose 和 Room；iOS 使用 SwiftUI；服务端使用 Kotlin 与 Spring Boot；官网使用 Vue 与 Nuxt。
