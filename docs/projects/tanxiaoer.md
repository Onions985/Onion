摊小二（TanXiaoEr）是一款面向摆摊商家的随身经营工具。从理货、备货到开单、收款和收摊，把容易遗漏的细节记录清楚，让经营者把注意力留给眼前的生意。

## 围绕商家的工作流程

- **商品与 SKU**：管理商品、规格、价格和库存，支持多店铺切换。
- **快速开单**：通过商品列表或扫码加购，核对数量与优惠，计算应收金额。
- **收款与订单**：展示商家的静态收款码，由商家核实到账并手动确认，完成订单后扣减库存。
- **订单与统计**：回看经营记录，了解销售与库存变化。
- **皮肤与使用指南**：用完整的视觉资源包提供小熊森林等界面体验，官网提供分步操作指南。

## Android 与 iOS 的不同侧重点

两端都围绕本地商品、SKU、多店铺、库存、开单、优惠和订单统计展开。Android 还提供仓库调拨、出摊收摊、赠品与整单赠送，以及云端会员和分仓协作相关能力；iOS 当前以本地经营数据为主。

免费本地模式把经营数据保存在当前设备。Android 云端模式用于需要跨设备与多人协作的场景，经营操作需由服务端确认后同步。

## 技术实现

Android 使用 Kotlin、Jetpack Compose 与 Room；iOS 使用 SwiftUI；服务端使用 Kotlin 与 Spring Boot；独立官网采用 Vue 与 Nuxt。各端围绕相同的经营规则维护自己的实现。
